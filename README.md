# RFB Battle Music

**Русский** · [English](README.en.md)

Мод для **Deep Rock Galactic**: музыка миссий заменена на свои треки. Рой, затяжные бои, эвакуация,
дредноуты и разлом Core Stone, machine event, экраны загрузки и статистики, фоновая музыка пещер.

- **Только звук.** В паке лежат одни SoundWave-ассеты с ванильными именами, кью и блюпринты не тронуты.
- **На клиенте.** Музыку слышит только тот, у кого стоит мод.
- **Каждый трек стартует с дропа**, петли затяжного боя замыкаются на дроп.

Продолжение [RFB Jukebox](https://github.com/realfamousbae/drg-rfb-jukebox-music): тот же пайплайн,
другая часть игры.

## Как это устроено

Музыку миссий играют Sound Cue из `Content/Audio/Music/**`: один кью на одну песню, внутри Wave Player
с одной SoundWave. Мод подменяет эти SoundWave своими с теми же путями и именами, кью остаются
ванильными и продолжают решать, когда и что включать. Подробный разбор категорий, кью и
длительностей: [docs/mission-music.md](docs/mission-music.md).

| Категория | Слотов | Ванильная длина | Петля | Когда играет |
|---|---|---|---|---|
| `swarm` | 10 | 2:12 – 3:46 | 5 из 10 | объявленный рой |
| `pressure` | 7 | 2:10 – 3:32 | все | затяжной бой |
| `extraction` | 6 | 2:01 – 5:17 | все | эвакуация к дроп-поду |
| `boss` | 4 | 2:15 – 4:30 | все | дредноуты, разлом Core Stone |
| `machine` | 1 | 1:27 | да | Machine Event |
| `endscreen` | 1 | 2:19 | нет | экран статистики |
| `deepdive` | 1 | 0:52 | да | между этапами Deep Dive |
| `ambient` | 14 | 4:32 – 9:05 | все | фон пещеры; `St_Deep_Master_1` ещё и экран загрузки |

Что уже известно и чего пока нет:

- У волн миссий нет SoundClass и затухания: они на кью. Волны `*_Master_*` стриминговые, семь петель
  `pressure` нет, их аудио лежит в `.uexp`. Импорт повторяет эти флаги.
- Почти все кью миссий **зацикливают волну** и играют её по кругу, пока игра не остановит кью: эмбиент,
  босс, эвакуация, machine event, Deep Dive и половина роя. Один раз играют экран статистики и пять кью
  роя. Поэтому для зацикленных слотов рендерится бесшовная петля от дропа до точки `end` из `cuts.csv`.
- **Не проверено в игре**, обрезает ли игра трек по ванильной длительности, как джукбокс, и нет ли провала
  на стыке петель. Проверка: «ЧСВ» в рое `St_Tick_Master_1` (135 с против ванильных 226 с), откачка на
  Refining или Ommoran в Escort. Если обрезает, собирать с `-FitSlots`.
- `data/mission_slots.csv` снят с живого пака игры 1.40 (25.10.2026). По сравнению с шаблоном U38P10
  добавился слот разлома Core Stone, остальное совпало.

## Структура

```
data/
  playlist.tsv         треклист: исполнители, название, длительность, ссылка на YouTube, обрезка клипа
  cuts.csv             с какой секунды начинается каждый трек (хук/дроп) и где кончается фрагмент
  mission_slots.csv    все волны музыки миссий: категория, кью, ванильные длительность и флаги
  mapping.csv          какой трек в какой слот (образец: mapping.example.csv)
docs/
  mission-music.md     разбор музыкальной системы миссий
  tracklist.md         раскладка треков по слотам с обоснованием
tools/
  scan_slots.py        список волн и кью из пака игры (repak unpack) или из Audio.zip шаблона
  fetch_tracks.py      скачивает треки из playlist.tsv в tracks/ (WAV 24 бит / 48 кГц)
  find_cuts.py         предлагает start/end для cuts.csv по кривой громкости и темпу
  prepare_tracks.py    громкость, срезы, петли, раскладка по слотам → build/import/
  ue_import.py         импорт WAV в UE-проект как SoundWave с ванильными флагами
  collect_cooked.py    берёт из cook только ассеты слотов
  build.ps1            всё по порядку: подготовка → импорт → cook → пак → zip
modio/
  description.md       тексты и настройки страницы мода на mod.io
  logo.png             обложка мода на mod.io
tracks/                аудио, в git не хранится
CHANGELOG.md           история версий
```

## Сборка

Нужны Windows, **UE 4.27.2**, [Audio-Modding-Template](https://github.com/DRG-Modding/Audio-Modding-Template)
(в `FSD.uproject` включены `PythonScriptPlugin` и `EditorScriptingUtilities`, папка
`Audio/SoundControl` в Directories to never cook), [repak](https://github.com/trumank/repak),
Python 3.8+ (только стандартная библиотека), ffmpeg, yt-dlp. Путь к репозиторию без пробелов.

```
python tools/fetch_tracks.py
powershell -ExecutionPolicy Bypass -File tools\build.ps1 -Project <template>\FSD.uproject -Repak <repak.exe>
```

Результат: `dist\RFB_BattleMusic_P.pak` и `dist\RFB_BattleMusic.zip` для mod.io. Редактор UE при сборке
должен быть закрыт. Путь к UE 4.27 скрипт находит через Epic Launcher, вручную: `-UERoot`. Продолжить с
середины: `-SkipPrepare`, `-SkipImport`, `-SkipCook`.

Параметры:

- `-Categories swarm,pressure,extraction,boss` — какие категории заменять; остальные остаются ванильными.
  По умолчанию все категории миссий, включая `ambient`.
- `-FitSlots` — рендерить каждый слот ровно в ванильную длину (если игра обрезает по ней).
- `-Volume 1.5` — множитель громкости всех волн, если в игре музыка тише ванили.
- `-TargetLufs -11` — целевая громкость. Ванильные экспорты можно померить:
  `python tools/prepare_tracks.py measure <файлы>`.

Для локального теста `.pak` удобно ставить через [mint](https://github.com/trumank/mint). Перед игрой с
модом с mod.io тестовую копию из mint убрать, иначе музыка окажется в двух паках.

Новая версия: запись в `CHANGELOG.md`, zip в тот же мод на mod.io (Files → Upload file) и GitHub-релиз
`vX.Y.Z` с `RFB_BattleMusic-X.Y.Z.zip` и его SHA-256.

### Треки

- `fetch_tracks.py` скачивает лучшее аудио по ссылке из `playlist.tsv`. Строка N становится файлом
  `tracks/NN Исполнители - Название.wav`. Колонка `trim` (`START-END`, секунды) обрезает клип до песни.
- `fetch_tracks.py` не скачивает строку с той же ссылкой и обрезкой второй раз: один трек может стоять в
  нескольких слотах с разными фрагментами, файл копируется.
- `cuts.csv`: `start` — с какой секунды трек стартует (хук или дроп), `end` — где фрагмент кончается
  (пусто = до конца). Для зацикленных слотов `end` — точка замыкания петли на границе такта, а секунды перед
  дропом подклеиваются к концу, чтобы при повторе музыка возвращалась на дроп без шва.
  `python tools/find_cuts.py` предлагает значения по кривой баса и темпу (`--profile N` печатает кривую
  трека), дальше правка на слух.
- `mapping.csv`: трек на слот, по имени волны или номеру строки плейлиста. Слоты без строки заполняются
  по кругу оставшимися треками.

## После патча DRG

```
repak unpack -i FSD/Content/Audio/Music -o <dir> "<DRG>\FSD\Content\Paks\FSD-WindowsNoEditor.pak"
python tools/scan_slots.py <dir>\FSD\Content\Audio\Music
git diff data/mission_slots.csv
```

Если волны и длительности не изменились, пересобирать не нужно.
