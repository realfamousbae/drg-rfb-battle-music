# rfb-battle-music

Мод для Deep Rock Galactic: заменяет музыку миссий (рой, затяжной бой, эвакуация, дредноут и т. д.)
на свои треки. Как устроена музыка игры: [docs/mission-music.md](docs/mission-music.md). Как собирать:
[README.md](README.md). Продолжение мода джукбокса `realfamousbae/drg-rfb-jukebox-music`, пайплайн тот же.

- Аудио (`tracks/`, `build/`, `pak/`, `dist/`) в git не коммитить.
- Треки и ссылки в `data/playlist.tsv`, раскладку в `data/mapping.csv` утверждает пользователь. Без его
  согласия не менять.
- `data/mission_slots.csv` снят с живого пака игры 1.40 на Windows (25.10.2026). После патчей DRG
  пересканировать (`tools/scan_slots.py`): могут появиться новые кью. `data/mission_cues.csv` пока снят с
  шаблона U38P10 (Core Stone дописан руками по скану его кью из пака 1.40 27.10.2026), при пересканировании
  перезапишется.
- Не доказано, что игра обрезает музыку миссий по ванильной длительности. `--fit-slots` включать только
  после теста в игре.
- Перед загрузкой чего-либо на mod.io спрашивать пользователя.
- Скрипты кроссплатформенные (Python 3.8+, только стандартная библиотека, ffmpeg). Всё про UE и пак
  рассчитано на Windows. Общение с пользователем на русском, код и комментарии на английском.
